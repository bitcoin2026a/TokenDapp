# This is EfforlessOrder Sale Sites

## Running the App 👩‍💻  

### Clone the Repository  

```sh  
git clone https://github.com/bitcoin2026a/TokenDapp.git
cd TokenDapp
```  

### Install Node:

```sh
install node v22.10.0
```

### Install Dependencies:

```sh
npm install
```

### Run The Application:

```sh
npm start
```
